ailocal.

Download, serve and expose local LLMs to your coding harness - Pi, Codex and Claude Code - on your own GPU, reachable from anywhere.

Install

$ curl -fsSL https://zottiben.github.io/ai-local/install.sh | sh

Linux, x86_64 or aarch64. Needs llama.cpp with the Vulkan backend. Once installed, ailocal update re-runs the same script.

Set up

$ ailocal setup --model ollama:gemma4:12b

Checks prerequisites, installs a model, starts the systemd units and points your harnesses at the gateway.

Then

$ ailocal model ls
NAME                  SIZE  ARCH     KV/TOK   TRAINED   MAX CTX
gemma4-12b-Q4_K_M      6 G  gemma4   11 KiB      256k      256k

$ pi --provider llama.cpp --model gemma4-12b-Q4_K_M

What it does

  • Refuses loads that would exceed your VRAM
  • Sizes context from the model's own KV geometry
  • Resumable, checksum-verified downloads
  • OpenAI and Anthropic APIs on one port
  • Bearer auth, so it can face a tunnel
  • Swaps models on demand, one resident
